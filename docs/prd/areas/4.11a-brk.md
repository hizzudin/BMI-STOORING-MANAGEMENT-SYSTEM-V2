# 4.11a BRK: Report Breakdown (P0, risk: high)

> Part of the BMI Stooring System spec (§4 functional requirements, area BRK). Core rules, roles, state machines, business rules and decisions: [PRD.md](../../../PRD.md). Section numbers and IDs are the same across the whole spec.

Goal: a person in the field reports a problem in seconds and carries no SPK work. The report is a note with photos and an urgency; the Planner or System Admin turns it into an SPK and keeps it as the reference (DEC-109).
