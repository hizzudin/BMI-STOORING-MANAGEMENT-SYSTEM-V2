# 4.2 ENG: assignment engine (P0, risk: critical)

> Part of the BMI Stooring System spec (§4 functional requirements, area ENG). Core rules, roles, state machines, business rules and decisions: [PRD.md](../../../PRD.md). Section numbers and IDs are unchanged from the single-file PRD v2.4.


Goal: run the steps of an SPK in order while verification happens in parallel. States: `SM-STEP` (3.3).
