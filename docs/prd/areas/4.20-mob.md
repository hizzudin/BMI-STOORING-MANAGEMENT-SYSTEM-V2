# 4.20 MOB: mobile app (risk: high; P0 in R1 step 7 for Driver, Field Coordinator, Mechanic and System Admin; P1 for Supervisor and GM, DEC-98)

> Part of the BMI Stooring System spec (§4 functional requirements, area MOB). Core rules, roles, state machines, business rules and decisions: [PRD.md](../../../PRD.md). Section numbers and IDs are unchanged from the single-file PRD v2.4.


Goal: one mobile app for the roles that work in the field, with the same data, rules and scope lock as the web.
