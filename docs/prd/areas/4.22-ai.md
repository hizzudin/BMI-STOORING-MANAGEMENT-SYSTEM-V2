# 4.22 AI: AI assistant (P1)

> Part of the BMI Stooring System spec (§4 functional requirements, area AI). Core rules, roles, state machines, business rules and decisions: [PRD.md](../../../PRD.md). Section numbers and IDs are unchanged from the single-file PRD v2.4.


| ID | P | Requirement | Screens | Data |
| --- | --- | --- | --- | --- |
| REQ-AI-001 | P1 | THE SYSTEM SHALL offer a collapsible sidebar on every web screen that takes questions in Indonesian or English and shortcuts such as `/summary <plate>` and `/audit-stock <sku>`, and streams the answer as markdown. | AI sidebar (no reference yet) |  |
| REQ-AI-002 | P1 | THE SYSTEM SHALL let the System Admin set an OpenAI or Anthropic API key (encrypted at rest), choose the model and switch provider. | [`Settings`](<../../../Design Artifact/settings/Settings.html#Settings>) | `ai_configurations` |
| REQ-AI-003 | P1 | IF the assistant attempts any insert, update or delete, THEN THE SYSTEM SHALL block it; the assistant SHALL read only vehicles, Surat Perintah Kerja, steps, stock cards, placement logs and tyres, through a read-only database account. |  | NFR-04 |
| REQ-AI-004 | P1 | THE SYSTEM SHALL add prepared context for fleet status, inventory audit and tyre longevity, and log every query (user, prompt, context, tokens). |  | `ai_query_logs` |
