# 4.5a MBL: Mobilisasi (mobilisation) step (P0, risk: high)

> Part of the BMI Stooring System spec (§4 functional requirements, area MBL). Core rules, roles, state machines, business rules and decisions: [PRD.md](../../../PRD.md). Section numbers and IDs are unchanged from the single-file PRD v2.4.


Goal: send a mechanic to the location of the vehicle and charge the stooring (mobilisation) fee, with proof that the mechanic travelled there. Mobilisasi is a registered assignment module (master data, PR-6), not code; it uses the standard step lifecycle `SM-STEP` (3.3) with the module contract noted there. It replaces the stooring behaviour that used to live on the Mechanic Action step (`REQ-MEC-007` to `REQ-MEC-009`, retired).
