# 4.8 CR: change request and amendment (P0)

> Part of the BMI Stooring System spec (§4 functional requirements, area CR). Core rules, roles, state machines, business rules and decisions: [PRD.md](../../../PRD.md). Section numbers and IDs are unchanged from the single-file PRD v2.4.


Goal: let an executor ask for a change to wrong SPK content while keeping authorized work under control. States: `SM-CR` (3.7), transitions T8 to T10 of `SM-SPK`.

| ID | P | Requirement | Screens | Data | Rules |
| --- | --- | --- | --- | --- | --- |
| REQ-CR-001 | P0 | THE SYSTEM SHALL let the executor of the open step submit a change request with what changes, the requested change and a reason; WHEN submitted, the SPK SHALL enter Pending\_Amendment without any approval. | [`ChangeRequest`](<../../../Design Artifact/spk/ChangeRequest.html#ChangeRequest>) | `spk_change_requests` |  |
| REQ-CR-002 | P0 | WHILE the SPK is Pending\_Amendment, THE SYSTEM SHALL freeze the open step and keep later steps Locked. | [`StepLocked`](<../../../Design Artifact/spk/StepLocked.html#StepLocked>), [`SPKDetail`](<../../../Design Artifact/spk/SPKDetail.html#SPKDetail>) | `status_before_amendment` |  |
| REQ-CR-003 | P0 | THE SYSTEM SHALL let the SPK creator revise the content of the open step and the steps after it (for example the part list or the work description) and add, remove or move steps that have not started; submitted and verified steps SHALL NOT change. IF the request changes the vehicle, THEN THE SYSTEM SHALL refuse it (cancel and recreate instead). | [`CreateSPKRevision`](<../../../Design Artifact/spk/CreateSPKRevision.html#CreateSPKRevision>) | `spk_change_requests.revision` |  |
| REQ-CR-004 | P0 | WHEN an Approver approves the revision, THE SYSTEM SHALL apply it, raise the amendment number, keep the earlier version in history, restore the earlier SPK status and let the step continue. | [`AmendmentReview`](<../../../Design Artifact/approvals/AmendmentReview.html#AmendmentReview>) | `spks.amendment_no`, `audit_logs` | BR-04 |
| REQ-CR-005 | P0 | WHEN an Approver rejects the revision with a reason, THE SYSTEM SHALL discard it, restore the earlier status and record the rejection. | [`AmendmentReview`](<../../../Design Artifact/approvals/AmendmentReview.html#AmendmentReview>) | `spk_change_requests` |  |
| REQ-CR-006 | P0 | IF an amendment would change a goods issue that is already posted, THEN THE SYSTEM SHALL refuse it; the correction is a reversal (`REQ-STK-008`). | [`CreateSPKRevision`](<../../../Design Artifact/spk/CreateSPKRevision.html#CreateSPKRevision>) |  |  |
| REQ-CR-007 | P0 | IF the SPK is Pending\_Verification, THEN THE SYSTEM SHALL refuse a change request \[A\]. | [`ChangeRequest`](<../../../Design Artifact/spk/ChangeRequest.html#ChangeRequest>) |  |  |
| REQ-CR-008 | P0 | THE SYSTEM SHALL let a revision change only the content of steps that are not yet submitted (the open step and the Locked steps after it); IF it would change content of a step that is already submitted or verified, THEN THE SYSTEM SHALL refuse it. A submitted step is corrected by the verifier returning it before verification (REQ-ENG-005), and posted stock by a reversal (REQ-STK-008) (DEC-72). | [CreateSPKRevision](<../../../Design Artifact/spk/CreateSPKRevision.html#CreateSPKRevision>), [ChangeRequest](<../../../Design Artifact/spk/ChangeRequest.html#ChangeRequest>) | spk\_change\_requests.revision | REQ-CR-006 |

| ID | Verifies | Acceptance criterion |
| --- | --- | --- |
| AC-CR-001 | REQ-CR-001, REQ-CR-002 | WHEN a change request is submitted, the SPK SHALL show Pending\_Amendment and the next step SHALL stay Locked. |
| AC-CR-002 | REQ-CR-005 | WHEN a revision is rejected, the original content SHALL remain and the step SHALL resume. |
| AC-CR-003 | REQ-CR-004 | WHEN a revision is approved, the amendment number SHALL rise by one and the old list SHALL stay in history. |
| AC-CR-004 | REQ-CR-003 | IF a change request asks to switch the vehicle, THEN THE SYSTEM SHALL refuse. |
| AC-CR-005 | REQ-CR-008 | IF a change request raised in step 3 asks to change the part list of the submitted Stock step 1, THEN THE SYSTEM SHALL refuse it; a request to change the work description of open step 3 SHALL be accepted. |
